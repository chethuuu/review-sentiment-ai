For this assignment I built ReviewSense, basically a sentiment checker for
reviews - paste in a review and it says positive or negative with a confidence
score. I used TF-IDF + Logistic Regression for the model instead of something
like a transformer, mainly because it's quick to train on my laptop, doesn't
need a GPU, and I can actually see which words the model is reacting to,
which is more useful for a small project like this than a black box model.

For data I used the NLTK movie_reviews dataset, its 2000 real movie reviews
(1000 pos, 1000 neg) from the Pang & Lee sentiment dataset, so its an actual
public dataset and not something I made up. data/build_dataset.py is the
script that pulls it down and turns it into data/reviews.csv. Got about 81%
accuracy on the test split which seems like a fair number for this kind of
model on real text.
